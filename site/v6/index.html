Open-source 3D topology optimization

Make a 3D part lighter and keep it stiff.

topopt takes the loads and the places that must stay, and writes a smooth STL file that you can print.

01

How it works

  1. Describe the part

    Say it in words, or give a YAML file and one STL file for each region.

  2. Run it and watch

    Your agent starts the run with the MCP tool run_topopt, or you type topopt run.

  3. Print the result

    The run writes final.stl, a smooth mesh, and metrics.json with the mass and the stiffness.

The hook example, from a clone of the repo

topopt check examples/hook/hook.yaml
topopt run examples/hook/hook.yaml --out runs/hook --dashboard

The option --dashboard opens the browser. It shows the shape as it forms.

02

Features

On your computer
Everything runs locally. The dashboard works with no internet.
Agent or command line
An MCP server with 27 tools, or the topopt command.
Live dashboard
Watch the 3D shape form. Replay a recorded run.
More than one load case
The hook example has two: a hanging shirt and a fast pull-off at an angle.
A smooth mesh
The final mesh is smooth. The fixed, load and keep-out regions keep their exact shape.
Print report
Overhang, plate contact, support estimate, bed fit and the thinnest member, in metrics.json.
Your printer
Name the printer. topopt fills in the bed and the type. The catalog has 15 printers.
Stress check
An optional extra checks the stress of the finished STL with topopt verify.

04

Install

Start with the Claude Code plugin. The other five clients use the same MCP server from a clone of the repo.

All clients need uv. It gets Python 3.12 by itself.

curl -LsSf https://astral.sh/uv/install.sh | sh

On a Mac, brew install uv also works. The fast solver needs the Xcode Command Line Tools: xcode-select --install.

Claude Code

Recommended Full steps for Claude Code

Add the plugin with two commands. Then type /topopt:start-here in claude. The first start takes 1 to 3 minutes.

claude plugin marketplace add chartergroup/topopt-demo#v0.1.0
claude plugin install topopt@topopt-demo

Claude Desktop

Full steps for Claude Desktop

git clone https://github.com/chartergroup/topopt-demo

uv run --no-project --python 3.12 packaging/mcpb/build.py

VS Code

Full steps for VS Code

In agent mode. Make this file in the clone as .vscode/mcp.json, then run MCP: List Servers and start topopt.

{
  "servers": {
    "topopt": {
      "type": "stdio",
      "command": "sh",
      "args": ["${workspaceFolder}/scripts/topopt-env.sh", "mcp"],
      "env": { "TOPOPT_WORKSPACE": "${workspaceFolder}" }
    }
  }
}

Gemini CLI

Full steps for Gemini CLI

Make this file in the clone as .gemini/settings.json. Start gemini in the repo root.

{
  "mcpServers": {
    "topopt": {
      "command": "sh",
      "args": ["scripts/topopt-env.sh", "mcp"]
    }
  }
}

05

Skills and roles

Two skills

start-here
Takes you from a part to a printable STL: check, run, dashboard and result.
part-to-topopt
Turns a plain description of a part into a problem YAML and region STL files.

Four roles

Lead design engineer
Finds the goal, the loads, the mounting and the print limits. Reviews the result.
CAD engineer
Makes the design space, the fixed regions, the load regions and the keep-outs.
FEA engineer
Sets up the loads and the supports, starts the run and reads the numbers.
Print engineer
Checks the bed fit, the thin members, the overhangs and the supports.

Claude Code gets the roles as sub-agents. A client without sub-agents gets the role texts from the MCP tool team_guide.

Sources: skills/start-here/, .claude/skills/part-to-topopt/, agents/ and topopt_mcp/roles/.

06

FAQ

Where does it run?
On your computer. The first start downloads Python 3.12 and about 200 MB of packages.
Which computers can I use?
A Mac with Apple silicon or a Linux x86_64 computer. An Intel Mac is best effort. Windows is not supported.
Do I need an agent?
No. The command line works alone: topopt check and topopt run <file.yaml> --out <dir>.
How long does a run take?
The hook example takes about 2.5 minutes on an M1 Mac. topopt check gives a time estimate before the run.
How do I update?
In a clone, run git pull --ff-only. For the plugin, remove the marketplace, add it with the new release tag and install again. The README section on updates has the steps.

07

Contributing

The code is in chartergroup/topopt-demo. Make a dev environment and run the tests.

uv venv --python 3.12
uv pip install -e ".[dev,mcp]"
.venv/bin/python -m pytest -n auto

On a Mac with Apple silicon, run sh topopt/native/build.sh first. The README has the details. CHANGELOG.md lists the changes of each release.
