# Icons: sources and licences

The files in this folder are one-colour SVG marks. The page draws them with CSS masks, so they follow the text colour. No mark was drawn
by hand: each file is a file of the open icon set named below. The brand marks belong to their owners. They are shown only to name the
linked service.
