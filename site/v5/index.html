3D topology optimization

Make a 3D part lighter and keep it stiff.

topopt writes a smooth STL file that you can print.

How it works

  1. 01

    Describe

    Give topopt the loads and the places that must stay. Use a YAML file, or describe the part in words.

  2. 02

    Run

    A live dashboard in the browser shows the shape while it forms.

  3. 03

    Print

    final.stl is a smooth mesh. metrics.json has the mass, the stiffness and a print report.

Install

The Claude Code plugin is the recommended route. The other clients use the same MCP server.

Claude Code Recommended

Full steps (README) 
claude plugin marketplace add chartergroup/topopt-demo#v0.1.0
claude plugin install topopt@topopt-demo

Then start claude and type /topopt:start-here. It needs uv, which gets Python 3.12 by itself. The first start takes 1 to 3 minutes.

Claude Desktop

Full steps (README) 
uv run --no-project --python 3.12 packaging/mcpb/build.py

Run it in a clone. Then open the .mcpb file with Claude Desktop.

Cursor

Full steps (clients.md) 
git clone https://github.com/chartergroup/topopt-demo

Open the folder in Cursor. The clone has .cursor/mcp.json.

Codex CLI

Full steps (clients.md) 
git clone https://github.com/chartergroup/topopt-demo && cd topopt-demo && codex

The clone has .codex/config.toml. Trust the project when Codex asks.

VS Code

Full steps (clients.md) 
"topopt": {
  "type": "stdio",
  "command": "sh",
  "args": ["${workspaceFolder}/scripts/topopt-env.sh", "mcp"],
  "env": { "TOPOPT_WORKSPACE": "${workspaceFolder}" }
}

In a clone, add this entry under servers in .vscode/mcp.json.

Gemini CLI

Full steps (clients.md) 
"topopt": { "command": "sh", "args": ["scripts/topopt-env.sh", "mcp"] }

In a clone, add this entry under mcpServers in .gemini/settings.json.

Skills and roles

Skills

  • start-hereTakes you from a part to a printable STL.
  • part-to-topoptTurns a plain description of a part into a problem YAML and region STL files.

The four roles

  • Lead design engineerSets the goal and the limits. Reviews the result.
  • CAD engineerBuilds the regions from the brief.
  • FEA engineerSets up and starts the run. Reads the numbers.
  • Print engineerChecks that the result can be printed.

The role files are in agents/.
