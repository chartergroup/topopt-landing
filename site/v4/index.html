3D topology optimization

Make a 3D part lighter and keep it stiff.

topopt removes the material that does little work and writes a smooth STL file that you can print.

How it works

  1. 01

    Describe the part

    Give one STL file for each region in a YAML file. Or describe the part in words.

  2. 02

    Run it and watch

    Your agent starts the run over MCP, or you use topopt run. The dashboard shows the shape form.

  3. 03

    Get a part to print

    You get a smooth final.stl and metrics.json: the mass, the stiffness and a print report.

topopt check examples/hook/hook.yaml
topopt run examples/hook/hook.yaml --out runs/hook --dashboard

Install

uv

curl -LsSf https://astral.sh/uv/install.sh | sh

The only prerequisite. It gets Python 3.12 by itself. On a Mac, brew install uv also works.

Claude Code recommended

claude plugin marketplace add chartergroup/topopt-demo#v0.1.0
claude plugin install topopt@topopt-demo

Then type /topopt:start-here in claude. Full steps for Claude Code

Claude Desktop

git clone https://github.com/chartergroup/topopt-demo
cd topopt-demo
uv run --no-project --python 3.12 packaging/mcpb/build.py

Open the .mcpb file in dist/mcpb/ with Claude Desktop. Full steps for Claude Desktop

Cursor

git clone https://github.com/chartergroup/topopt-demo

Open the folder in Cursor. The file .cursor/mcp.json is in the repo. Full steps for Cursor

Codex CLI

git clone https://github.com/chartergroup/topopt-demo
cd topopt-demo && codex

Trust the project. The file .codex/config.toml is in the repo. Full steps for Codex CLI

VS Code

{ "servers": { "topopt": {
  "type": "stdio", "command": "sh",
  "args": ["${workspaceFolder}/scripts/topopt-env.sh", "mcp"],
  "env": { "TOPOPT_WORKSPACE": "${workspaceFolder}" }
} } }

Save it as .vscode/mcp.json in a clone of the repo. Full steps for VS Code

Gemini CLI

{ "mcpServers": { "topopt": {
  "command": "sh", "args": ["scripts/topopt-env.sh", "mcp"]
} } }

Save it as .gemini/settings.json in a clone of the repo. Start gemini there. Full steps for Gemini CLI

Skills and roles

Skills

start-here
Checks the machine, then takes you from a part to a printable STL.
part-to-topopt
Turns a plain description of a part into a problem YAML and region STL files.

Four roles

Lead design engineer
Sets the goal, the loads and the print limits. Reviews the result.
CAD engineer
Builds the design space, the fixed and load regions, and the keep-outs.
FEA engineer
Sets up the loads, starts the run and reads compliance and stiffness.
Print engineer
Checks the fit on the bed, thin members, overhangs and supports.

The role texts are in agents/ and topopt_mcp/roles/.
